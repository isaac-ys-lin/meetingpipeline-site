Gemini API Key 申請教學。

Trace 採用使用者自備 Gemini API key。你可以在 Google AI Studio 建立 key，再到 app 的「設定」貼上使用。

先看這裡：本頁說明如何建立 Gemini API key、貼到 Trace，以及免費 API key、付費 API key、長音訊與會議紀錄成本要怎麼看；完整估算請看 模型與成本。

隱私重點：Trace 不內建 Gemini 帳號，也不內建共用 API key。為了完成轉錄、整理與分析，音檔、逐字稿、會議背景與生成結果會送到 Gemini API。更多資料處理方式請看 隱私政策。

建立 Gemini API key

  1. 打開 Google AI Studio。 前往 Google AI Studio，使用你的 Google 帳號登入。
  2. 進入 API key 頁面。 在 AI Studio 找到 API key 相關入口，或直接參考 Google 的 Gemini API key 官方文件。
  3. 建立新的 key。 依照 Google AI Studio 畫面建立 key。請把 key 視為密碼，不要貼到公開文件、截圖、聊天訊息或客服回報內。
  4. 貼到 Trace。 打開 Trace 的「設定」，把 key 貼到「Gemini API key」欄位。key 只會存在 iOS Keychain。

免費 API key 與免費額度

Google AI Studio 通常可以先建立免費 API key，部分模型也會提供免費層級或試用額度。不過免費額度、每日請求數、每分鐘請求數、區域與模型可用性都可能調整；請以 Google 的官方價格與限制頁面為準。

以 Trace 目前的 Gemini 3.1 Flash-Lite 模型來看，免費額度可先測 1 到 2 小時內的會議音訊；不過這不是 app 的音訊長度限制，主要受免費 API key 額度限制。Trace 內建模型 API 冷卻機制，遇到速率限制時會倒數重送，所以較長的音訊仍有機會免費完成。長會議音檔若要穩定生成結果，建議將 API key 綁定付費帳單。

付費 API key 與付費額度

如果免費額度不夠，或你想轉錄更長的音訊，可以到 Google AI Studio 或 Google Cloud 為 API key 所屬專案開通付費帳單。開通後，Trace 的 Gemini API 用量會依 Google 的付費價格與限制計算；實際費率、限制與可用模型仍會依帳號、專案、區域、模型與 Google 政策調整。長音訊成本主要取決於音訊 input tokens、逐字稿 output tokens、會議紀錄分析 input / output tokens；完整公式與範例請看 Trace 模型與成本。Trace 收費完全透明，不另建立後端成本，讓你可以直接使用 Google 公開的計費標準。

Trace 的設計取向

使用者自備 API key

Trace 不代管 Gemini 帳號，也不內建共用 API key。你的用量、費率與限制取決於你自己的 Google 專案。

本機保存紀錄

會議紀錄、逐字稿、生成結果與處理狀態保存在你的裝置上，方便稍後查看、重試與分享。

長音訊匯入

Trace 針對錄製或匯入長音訊的流程設計，適合把完整會議整理成可回看的紀錄。

一次解鎖

App 採一次性解鎖模式；Gemini API 使用費由 Google 依你的 API key 所屬專案與帳單方案計算。

會議背景

錄製或匯入音檔時，Trace 可以讓你補上會議背景，例如客戶名稱、產品名稱、議程、常用縮寫或說話人脈絡。這些文字會與音檔、逐字稿、模板與生成草稿一起送到 Google Gemini API，幫助 Gemini 更準確辨識專有名詞與領域用語。

會議背景建議保持簡短、具體；多數會議用一到五個重點就足夠。不要貼上 API key、密碼、私人憑證，或任何你不想交由 Gemini 處理的資訊。

會議背景會增加少量文字 input tokens。成本估算請看 模型與成本。

會送到 Gemini 的資料

為了完成轉錄、會議紀錄整理、分析與事實檢核，Trace 會把匯入的音檔、逐字稿、你輸入的會議背景，以及 Gemini 產生或 app 整理出的生成結果送到 Google Gemini API。

Gemini API key 只存在 iOS Keychain，不會寫進會議紀錄、逐字稿、Markdown 匯出檔或 app 內的會議資料。更多資料處理方式請看 Trace 隱私政策。
