MeetingPipeline 模型與成本。

MeetingPipeline 目前提供 Gemini 3.1 Flash-Lite 與 Gemini 3.5 Flash。這頁把適合情境、音訊 token 算法、逐字稿輸出與會議紀錄分析成本放在一起看。

目前模型：MeetingPipeline 提供 Gemini 3.1 Flash-Lite 與 Gemini 3.5 Flash；實際選用哪個模型由使用者依會議情境決定。

估算限制：Google 價格、免費額度與速率限制會調整。本頁只用公開 paid tier 數字抓量級，並非保證費用。

成本怎麼算

Gemini 音訊理解使用固定 token 算法：每秒音訊約 32 input tokens。1 分鐘約 1,920 tokens，1 小時約 115,200 tokens。MeetingPipeline 的完整流程還包含逐字稿輸出，以及把逐字稿送回模型整理成會議紀錄。

轉錄成本 = 音訊 input tokens × 轉錄模型音訊 input 單價 + 逐字稿 output tokens × 轉錄模型 output 單價

分析成本 = (逐字稿 tokens + 會議背景 / 模板 tokens) × 分析模型文字 input 單價 + 會議紀錄 output tokens × 分析模型 output 單價

總成本 = 轉錄成本 + 分析成本

成本估算假設

  • 使用 Google Gemini API Standard paid tier 公開價格。
  • 轉錄模型：Gemini 3.1 Flash-Lite，音訊 input USD 0.50 / 1M tokens，文字 input USD 0.25 / 1M tokens，output USD 1.50 / 1M tokens。
  • 分析模型：Gemini 3.5 Flash，input USD 1.50 / 1M tokens，output USD 9.00 / 1M tokens。
  • 每 1 小時會議粗估產生 12,000 transcript output tokens。
  • 會議背景、模板與分析指令粗估固定 2,000 input tokens。
  • 每 1 小時會議粗估輸出 4,000 meeting notes output tokens。
  • NTD 換算以 1 USD 約 NTD 30～33 粗估。
