MeetingPipeline 模型與成本。

MeetingPipeline 目前提供 Gemini 3.1 Flash-Lite 與 Gemini 3.5 Flash。這頁提供適合情境、音訊 token 算法、逐字稿輸出與會議紀錄分析成本的完整分析。

目前模型：MeetingPipeline 提供 Gemini 3.1 Flash-Lite 與 Gemini 3.5 Flash；實際選用哪個模型由使用者依會議情境決定。

估算限制：若使用免費 API key 並仍在 Google 免費額度內，通常不會產生 API 費用；本頁用公開 paid tier 數字抓付費量級。Google 價格、免費額度與速率限制會調整，並非保證費用。

成本怎麼算

Gemini 音訊理解以時間計算 token：每秒音訊約 32 input tokens。1 分鐘約 1,920 tokens，1 小時約 115,200 tokens。MeetingPipeline 會先取得逐字稿，再把逐字稿、會議背景與模板送到模型整理成會議紀錄。

長音訊可能會分段處理。同一段音訊在流程中被再次引用時，Google 帳單可能以 cached audio input 計算。本頁用這個情境估算常見量級，也列出未命中 cached input 時的保守上限。

轉錄成本 = 音訊 normal input + 可能的 cached audio input + 逐字稿文字 input + 逐字稿 JSON output。

分析成本 = (完整逐字稿 + 會議背景 / 模板 / 分析指令) × 分析模型 input 單價 + 會議紀錄 output tokens × 分析模型 output 單價。

總成本 = 轉錄成本 + 分析成本

其他成本：會議背景與檢核

匯入音檔時，可以補上會議背景，例如客戶名稱、產品、議題或常用縮寫。這些上下文會幫助模型辨識專有名詞、人物、產品與常見用語，讓逐字稿更接近實際會議內容。

這些上下文會增加少量文字 input tokens，但成本通常很低。以 2,000 input tokens 粗估，Flash-Lite 文字 input 約 USD 0.0005，不到 NTD 0.02 元；若進入 3.5 Flash 分析，約 USD 0.003，也大約是 NTD 0.09～0.10 元。

事實檢核成本：若另外執行事實檢核，1 小時會議可再抓約 USD 0.051 (NTD 1.5～1.7 元) 的量級。

本頁的 cached audio input 只用來抓成本量級；MeetingPipeline 不會替使用者建立後端快取。若 Google 對音訊重複引用或快取命中採用不同計算，請以你的 Google 帳單與官方 pricing 為準。
