Trace 模型與成本。

一小時會議，用 App 推薦組合大約 NT$4；在 Google 免費額度內不收 API 費用。下面先看結論與怎麼選模型，完整的計算方式放在最後。

一小時會議，大約多少錢？

多數人從免費 API key 開始

在 Google 免費額度內，Trace 使用的三個模型都不收 API 費用。本頁的金額是專案開通付費後的量級；免費使用時，可以把它當成「超過額度、改用付費時大約要付多少」的參考。

  • 額度以專案計算，不是以 key 計算；同一個專案建立多把 key，會共用同一份額度。
  • 每日請求數（RPD）在美國太平洋時間午夜重置，約為台灣時間下午 3 點（美國夏令時間期間）或下午 4 點。
  • 長錄音會分段送出，每一段、每一次重試都算一次請求。遇到速率限制時，Trace 會依 Google 的回應等待後重試；已完成的段落會保留，額度恢復後可以按「繼續轉錄」，只處理未完成的部分。
  • 免費層級送出的內容，Google 可能用來改善產品，也可能經人工審查，因此 Google 要求免費服務不要送出敏感、機密或個人資料。這類會議建議改用已開通付費的專案；詳見隱私政策。
  • 專案開通帳單後會升級為付費層級，改依付費價格計費。

Google 沒有公開免費額度的固定數字，實際限制依帳號、專案與模型而不同，請到 Google AI Studio 的 Rate Limit 頁查看。還沒有 key？請看 Gemini API Key 教學。

錢花在哪裡？

會議越長，成本跟著增加

其他成本：會議背景與檢核

匯入音檔時，可以補上會議背景，例如客戶名稱、產品、議題或常用縮寫。背景資訊可協助支援文字提示的轉錄模式辨識專有名詞，也可用於後續內容整理。Gemini 3.5 Transcribe 的時間戳與說話人功能不支援自訂詞彙提示；使用這個模式時，背景資訊用於後續分析，不保證改善原生逐字稿的名詞辨識。請參考 Google 功能相容性說明。

這些上下文會增加少量文字 input tokens，但成本通常很低。以 2,000 input tokens 粗估，3.5 Flash-Lite input 約 USD 0.0006，不到 NTD 0.02 元；若進入 3.8 Flash 分析，約 USD 0.0015，大約是 NTD 0.05 元。

事實檢核成本：若另外執行約 16,000 input／3,000 output tokens 的 3.8 Flash 檢核，1 小時會議可再抓約 USD 0.023 (NTD 0.7～0.8 元) 的量級。

本頁的 cached audio input 只用來抓成本量級；Trace 不會替使用者建立後端快取。若 Google 對音訊重複引用或快取命中採用不同計算，請以你的 Google 帳單與官方 pricing 為準。

計算方式、估算假設與完整表格

成本怎麼算

Gemini 音訊理解以時間計算 token：每秒音訊約 32 input tokens。1 分鐘約 1,920 tokens，1 小時約 115,200 tokens。Trace 會先取得逐字稿，再把逐字稿、會議背景與模板送到模型整理成會議紀錄。

長音訊可能會分段處理。同一段音訊在流程中被再次引用時，Google 帳單可能以 cached audio input 計算。本頁用這個情境估算常見量級，也列出未命中 cached input 時的保守上限。

轉錄成本 = 音訊 normal input + 可能的 cached audio input + 逐字稿文字 input + 逐字稿 JSON output。

分析成本 = (完整逐字稿 + 會議背景 / 模板 / 分析指令) × 分析模型 input 單價 + 會議紀錄 output tokens × 分析模型 output 單價。

總成本 = 轉錄成本 + 分析成本
