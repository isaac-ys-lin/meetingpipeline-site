MeetingPipeline Privacy Policy.

MeetingPipeline uses your own Gemini API key and does not include a built-in account, API key, or cloud sync service. This page explains how audio, transcripts, meeting background, generated content, local storage, and tracking are handled.

Overview

MeetingPipeline is an iPhone app that turns imported meeting audio into transcripts, meeting notes, decisions, risks, action items, and fact-checking drafts. MeetingPipeline uses a bring-your-own Gemini API key model. It does not include a built-in account, built-in API key, or built-in cloud sync service.

Data processed for app functionality

To provide app functionality, MeetingPipeline may process content you provide or generate, including:

  • Imported audio files.
  • Transcripts.
  • Meeting background you enter.
  • Generated results such as meeting notes, action items, decisions, risks, and fact-checking drafts.

To provide app functionality, MeetingPipeline sends imported audio, transcripts, meeting background, and generated drafts to the Google Gemini API for transcription, analysis, meeting-note generation, and fact-checking.

Google's handling of Gemini API data is governed by the Google terms and settings that apply to your Gemini API usage.

Gemini API key

You provide your own Gemini API key. The key is stored only in iOS Keychain and is used to call the Google Gemini API. It is not written into meeting notes, transcripts, Markdown exports, or in-app meeting data.

MeetingPipeline does not provide a built-in Gemini account or built-in API key. You can remove the saved key in Settings.

Local storage

MeetingPipeline stores meeting notes, transcripts, generated results, processing state, and necessary app settings on your device so you can review, retry, and share results later. These records stay on your device unless you choose to share, export, back up, or transmit them using system features.

Tracking and accounts

MeetingPipeline does not track you across apps or websites, does not require a built-in account sign-in, and does not collect account passwords.

Your choices

  • You can choose not to enter a Gemini API key, but Gemini transcription and analysis will not work without one.
  • You can remove the saved Gemini API key in Settings.
  • You can delete meeting records and local results in the app.
  • You can share or export results using iOS system features.

Contact

For privacy questions or support needs, please start with the MeetingPipeline Support page.
