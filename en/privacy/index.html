Trace Privacy Policy.

Trace uses your own Gemini API key and does not include a built-in account, API key, or cloud sync service. This page explains how audio, transcripts, meeting background, generated content, local storage, and tracking are handled.

Overview

Trace is an iPhone and iPad app that records or imports meeting audio and turns it into transcripts, meeting notes, decisions, risks, action items, and fact-checking drafts. Trace uses a bring-your-own Gemini API key model. It does not include a built-in account, built-in API key, or built-in cloud sync service.

Data processed for app functionality

To provide app functionality, Trace may process content you provide or generate, including:

  • Recorded or imported audio files.
  • Transcripts.
  • Meeting background you enter.
  • Generated results such as meeting notes, action items, decisions, risks, and fact-checking drafts.

To provide app functionality, Trace sends recorded or imported audio, transcripts, meeting background, and generated drafts to the Google Gemini API for transcription, analysis, meeting-note generation, and fact-checking.

Google's handling of Gemini API data is governed by the Google terms and settings that apply to your Gemini API usage.

Long-audio transcription uses the Gemini Interactions API to continue context across transcription windows. Google stores each Interaction request and response for that continuation. Trace attempts to delete related Interactions and uploaded files after that audio section completes, is cancelled, or reaches a terminal failure. Deletion is best effort; if a network or service failure prevents immediate deletion, the data may remain under Google's retention policy. Google currently documents 1-day retention for Free Tier and 55-day retention for Paid Tier, with Paid Tier project settings of 7, 14, 28, or 55 days in AI Studio. Users can also view and manage stored Interactions in Google AI Studio.

Gemini API key

You provide your own Gemini API key. The key is stored only in iOS Keychain and is used to call the Google Gemini API. It is not written into meeting notes, transcripts, Markdown exports, or in-app meeting data.

Trace does not provide a built-in Gemini account or built-in API key. You can remove the saved key in Settings.

Local storage

Trace stores recordings, meeting notes, transcripts, generated results, processing state, and necessary app settings on your device so you can review, retry, play, and share results later. These records stay on your device unless you choose to share, export, back up, or transmit them using system features.

Tracking and accounts

Trace does not track you across apps or websites, does not require a built-in account sign-in, and does not collect account passwords.

Your choices

  • You can choose not to enter a Gemini API key, but Gemini transcription and analysis will not work without one.
  • You can remove the saved Gemini API key in Settings.
  • You can delete meeting records and local results in the app.
  • You can share or export results using iOS system features.

Contact

For privacy questions or support needs, please start with the Trace Support page.
