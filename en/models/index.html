MeetingPipeline Models & Costs.

MeetingPipeline currently uses Gemini models for transcription and meeting-note analysis. This page explains audio token estimates, meeting-background input, and cost ranges.

Current models: MeetingPipeline can use Gemini models for transcription and analysis. Your selected model, Google project, and billing setup control the final cost.

Estimate limits: If your API key is still inside Google's free tier, you may not incur API charges. Google pricing, free quotas, and rate limits can change, so use this page as a practical estimate rather than a guaranteed bill.

How audio cost is estimated

Gemini audio understanding is commonly estimated by duration: one second of audio is roughly 32 input tokens. One minute is about 1,920 tokens, and one hour is about 115,200 tokens. MeetingPipeline then uses the transcript, meeting background, and templates to produce meeting notes.

Longer audio may be processed in stages. The actual bill depends on model choice, transcript density, generated output length, cached input behavior, and Google's current Gemini API pricing.

Meeting background and review costs

Meeting background usually adds a small number of text input tokens. It can improve names, acronyms, product terms, and agenda-specific wording, while the exact bill remains controlled by your Google project and Gemini API pricing.

Fact-checking or additional review passes can add more input and output tokens. If you run extra checks after the first meeting-note draft, estimate them as separate Gemini API calls.

Typical cost drivers

Audio length About 115,200 tokens per hour

Audio input scales mostly with duration, before model-specific billing details are applied.

Transcript density More speech means more output

Fast multi-speaker meetings usually produce more transcript and analysis tokens.

Generated notes Detailed drafts cost more

Longer meeting notes, action items, risks, and fact-checking drafts add output tokens.
