Trace 隱私政策。

Trace 採用使用者自備 Gemini API key，不內建帳號、API key 或雲端同步服務。本頁說明音檔、逐字稿、會議背景、生成內容、本機儲存與 tracking 的處理方式。

概覽

Trace 是一款 iPhone 與 iPad app，用來錄製或匯入會議音檔，並整理成逐字稿、會議紀錄、決策、風險、待辦與事實檢核內容。Trace 採用使用者自備 Gemini API key 的模式，不內建帳號、不內建 API key，也不提供內建雲端同步服務。

為了 app 功能而處理的資料

為了完成 app 功能，Trace 可能處理下列使用者提供或產生的內容：

  • 錄製或匯入的音檔。
  • 逐字稿。
  • 使用者輸入的會議背景。
  • 使用者選擇或編輯的模板指示。
  • Gemini 產生或 app 整理出的生成結果，例如會議紀錄、待辦、決策、風險與事實檢核內容。

Trace 會從使用者的裝置收集上述內容，並只在完成使用者要求的功能時，傳送給第三方服務 Google Gemini API，用來完成轉錄、會議紀錄整理、分析與事實檢核。Trace 不會把這些內容用於廣告或跨 app／網站 tracking。

在第一次傳送前，Trace 會在 app 內列出資料類型、接收方與用途，並取得使用者的明確同意。未同意或撤回同意後，Trace 不會開始新的 Gemini 轉錄，也不會在背景自動重試傳送。使用者可隨時在「設定」撤回同意；若日後揭露內容有實質變更，Trace 會再次取得同意。

Google 對 Gemini API 資料的使用取決於 API key 所屬專案適用的服務層級。依 Google 目前條款，使用免費服務時，Google 可能使用送出的內容與回覆來提供、改善及開發產品與機器學習技術，且人工審查員可能處理輸入與輸出；Google 因此要求免費服務不要送出敏感、機密或個人資料。使用付費服務時，Google 表示不會使用 prompts、檔案或回覆改善其產品，並依其資料處理附約處理；仍可能為安全、濫用防制及法律義務有限期記錄資料。

較長的音檔會分段處理；處理時音檔會上傳到 Google，並在處理期間暫時存放在他們的伺服器上。處理完成、被你取消，或最終失敗之後，Trace 會盡力刪除這些暫存的資料；如果遇到網路或服務異常而沒有刪成功，資料仍可能依 Google 的設定與保留政策繼續存在。Google 目前說明，為了偵測違反使用政策的行為，可能保留送出的內容、相關脈絡與回覆最多 55 天。

Trace 僅依上述目的將資料交由 Google Gemini API 處理，並依賴 Google 適用的 API 條款、隱私政策及付費服務資料處理承諾，對受託處理的資料提供與本政策一致的保護。Trace 不另行授權 Google 將資料用於本政策未揭露的 Trace 目的。

Gemini API key

使用者自備 Gemini API key。API key 只存在 iOS Keychain，用於呼叫 Google Gemini API，不會寫入會議紀錄、逐字稿、Markdown 匯出檔或 app 內的會議資料。

Trace 不會提供內建 Gemini 帳號或內建 API key。使用者可以在「設定」移除已儲存的 key。

本機儲存

Trace 會在本機儲存錄音、會議紀錄、逐字稿、生成結果、處理狀態與必要的 app 設定，以便使用者稍後開啟、重試、播放或分享結果。這些本機紀錄只存在使用者裝置上，除非使用者自行透過系統分享、匯出、備份或其他裝置功能傳送出去。

Tracking 與帳號

Trace 不追蹤使用者，不使用資料進行跨 app 或跨網站 tracking。Trace 不要求內建帳號登入，也不收集帳號密碼。

使用者選擇

使用者可以：

  • 不輸入 Gemini API key，但沒有 key 時無法完成 Gemini 轉錄與分析流程。
  • 在第一次傳送前拒絕 Google Gemini 資料分享。
  • 在「設定」撤回 Google Gemini 資料分享同意。
  • 在「設定」移除 Gemini API key。
  • 刪除 app 內的會議紀錄與本機結果。
  • 使用 iOS 系統提供的方式分享或匯出結果。
