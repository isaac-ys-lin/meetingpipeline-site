MeetingPipeline 隱私政策。

概覽

MeetingPipeline 是一款 iPhone app，用來將使用者匯入的會議音檔整理成逐字稿、會議紀錄、決策、風險、待辦與事實檢核內容。MeetingPipeline 採用使用者自備 Gemini API key 的模式，不內建帳號、不內建 API key，也不提供內建雲端同步服務。

為了 app 功能而處理的資料

為了完成 app 功能，MeetingPipeline 可能處理下列使用者提供或產生的內容：

  • 匯入的音檔。
  • 逐字稿。
  • 使用者輸入的會議背景。
  • Gemini 產生或 app 整理出的生成結果，例如會議紀錄、待辦、決策、風險與事實檢核內容。

上述音檔、逐字稿、會議背景與生成結果會送到 Google Gemini API，用來完成轉錄、會議紀錄整理、分析與事實檢核。Google Gemini API 的資料處理方式由使用者使用 Gemini API 時適用的 Google 條款與設定管理。

Gemini API key

使用者自備 Gemini API key。API key 只存在 iOS Keychain，用於呼叫 Google Gemini API，不會寫入會議紀錄、逐字稿、Markdown 匯出檔或 app 內的會議資料。

MeetingPipeline 不會提供內建 Gemini 帳號或內建 API key。使用者可以在「設定」移除已儲存的 key。

本機儲存

MeetingPipeline 會在本機儲存會議紀錄、逐字稿、生成結果、處理狀態與必要的 app 設定，以便使用者稍後開啟、重試或分享結果。這些本機紀錄只存在使用者裝置上，除非使用者自行透過系統分享、匯出、備份或其他裝置功能傳送出去。

Tracking 與帳號

MeetingPipeline 不追蹤使用者，不使用資料進行跨 app 或跨網站 tracking。MeetingPipeline 不要求內建帳號登入，也不收集帳號密碼。

使用者選擇

使用者可以：

  • 不輸入 Gemini API key，但沒有 key 時無法完成 Gemini 轉錄與分析流程。
  • 在「設定」移除 Gemini API key。
  • 刪除 app 內的會議紀錄與本機結果。
  • 使用 iOS 系統提供的方式分享或匯出結果。

聯絡方式

如有隱私問題或支援需求，請先參考 MeetingPipeline 支援頁。
