Trace Audio Notes & Insights

Trace 是 iPhone、iPad 與 Apple Watch 的會議錄音 app。直接錄音或匯入會議音檔，再用你自備的 Gemini API key 整理成逐字稿、會議紀錄、決策、風險與待辦。

在 App Store 下載 免費下載，含 5 次成功產出會議結果；之後可一次買斷解鎖。

Trace 27 秒介紹：用 Apple Watch 錄音、把多個音檔合成一場會議、整理決策風險與待辦、分享報告，以及 API key 只存在 iOS 鑰匙圈。影片含背景音樂，沒有旁白。

Trace 能做什麼

隨處開錄

在 App 內錄音、從「檔案」一次匯入多個音檔，或從「語音備忘錄」分享。Apple Watch 也能直接錄，連線可用時傳回 iPhone。

為長會議設計

音訊分段處理，進度與重試狀態清楚可見，中斷時保留未完成的工作。處理長音訊時，建議讓 Trace 保持在前景。

重點直接可用

產生逐字稿、會議紀錄、決策、風險、待辦與結構化摘要。服務未回傳時間時，會清楚標示本機推估的時間。

報告交給團隊

輸出 Markdown、HTML 或 PDF 報告，透過 Mail、「檔案」、AirDrop 與其他相容 App 分享。

你的資料與費用

API key 只存在 iOS 鑰匙圈。Trace 不需要帳號、不追蹤你，也沒有內建雲端同步；選取的音檔與文字只會為了轉錄與整理送到 Google Gemini，詳見隱私政策。Gemini API 用量不含在購買中：在 Google 免費額度內不收費，超過額度或開通付費後才依你的 Google 專案計費，詳見免費 API key 重點。

教學與說明

Gemini API Key 教學 從 Google AI Studio 建立 key、理解免費額度，並確認哪些資料會送到 Gemini。 模型與成本 說明 Trace 使用的 Gemini 模型、音訊 token 算法，以及長會議的 input / output 成本估算。 裝置端講者分析 了解講者標籤如何在裝置上改善、何時會自動略過，以及它與 Gemini 傳輸的差別。 隱私政策 說明音檔、逐字稿、Gemini API key、生成內容、本機儲存與 tracking 的處理方式。 支援 提供問題回報前檢查項目、教學入口與隱私摘要。
