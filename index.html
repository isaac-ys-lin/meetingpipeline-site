Trace Audio Notes & Insights

Trace 是一款 iPhone 與 iPad app，可直接錄下或匯入會議音檔，再使用你自備的 Gemini API key 整理成逐字稿、會議紀錄、決策、風險與待辦。

Gemini API Key 教學 從 Google AI Studio 建立 key、理解免費額度，並確認哪些資料會送到 Gemini。 模型與成本 說明 Trace 使用的 Gemini 模型、音訊 token 算法，以及長會議的 input / output 成本估算。 隱私政策 說明音檔、逐字稿、Gemini API key、生成內容、本機儲存與 tracking 的處理方式。 支援 提供問題回報前檢查項目、教學入口與隱私摘要。
