MeetingPipeline 公開文件。

MeetingPipeline 是一款 iPhone app，用來把匯入的會議音檔整理成逐字稿、會議紀錄、決策、風險、待辦與事實檢核內容。

這些公開頁面獨立於 private app source repository，讓 App Store Review 和使用者不需要 GitHub 權限，也能開啟隱私政策、支援頁和模型目錄。
