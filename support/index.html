聯絡支援前請先確認

請先確認：

  • 已在 Settings 輸入有效的 Gemini API key。
  • Gemini API key 所屬專案仍有可用額度。
  • App 保持在前景完成長音訊處理；若 iOS 中斷背景執行，可回到 app 重試未完成流程。
  • 匯入的檔案是 app 支援的音訊格式。

隱私摘要

MeetingPipeline 採用使用者自備 Gemini API key 的模式。API key 只存在 iOS Keychain，不會寫入會議紀錄或匯出檔。為了完成 app 功能，音檔、逐字稿、會議背景與生成結果會送到 Google Gemini API，用於轉錄、分析、會議紀錄整理與事實檢核。

MeetingPipeline 會在本機保存會議紀錄、逐字稿、生成結果與處理狀態，方便使用者重試、檢視與分享。MeetingPipeline 不追蹤使用者、不內建帳號、不內建 API key，也不提供內建雲端同步服務。
