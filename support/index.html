處理失敗時

Trace 可直接錄下會議，或從「檔案」與「語音備忘錄」匯入音訊，再使用你自備的 Gemini API key 產生逐字稿、會議紀錄、決策、風險與待辦。

如果處理失敗，請先確認下方項目。若問題仍重複發生，可以透過 App Store 評論留下公開回饋。

如果你還沒有 Gemini API key，請先看 Gemini API Key 申請教學。如果想估算長音訊處理成本，請看 模型與成本。

聯絡支援前請先確認

請先確認：

  • 已允許 Trace 使用麥克風；若曾拒絕，請到 iOS「設定」重新開啟權限。
  • 已在「設定」輸入有效的 Gemini API key。
  • Gemini API key 所屬專案仍有可用額度。
  • App 保持在前景完成長音訊處理；若 iOS 中斷背景執行，可回到 app 重試未完成流程。
  • 匯入的檔案是 app 支援的音訊格式。
  • 若錄音被電話、其他 App 或音訊裝置中斷，回到 Trace 確認錄音狀態後再繼續或完成。
  • 若音檔或結果分享失敗，重新開啟該項目並再次使用系統分享表單。

Gemini API 錯誤說明

Trace 使用你自己的 Gemini API key，App 會從裝置直接呼叫 Google Gemini API。下列錯誤通常代表 Gemini API、Google 專案、模型、額度或網路狀態需要處理，不是 Trace 服務中斷；此類 Gemini 請求是 App 從裝置直接送往 Google Gemini API。

快速判斷：如果看到 HTTP 500、503 或 504，通常可以先稍後重試、切換模型、縮短會議背景或輸入內容，並查看 Gemini API status。

錯誤 常見意思 你可以做什麼
HTTP 400 / INVALID_ARGUMENT 請求格式、內容或模型參數不被 Gemini 接受。 更新模型清單、縮短會議背景、重新匯入音檔後再試。
HTTP 403 / PERMISSION_DENIED API key、Google 專案權限或帳單狀態不允許這次請求。 確認 key 沒貼錯、沒有被封鎖，並檢查 Google AI Studio 或 Google Cloud 專案權限。
HTTP 404 / NOT_FOUND 模型或上傳到 Gemini 的檔案資源找不到。 在 App 設定更新模型清單，或稍後重新處理音檔。
HTTP 429 / RESOURCE_EXHAUSTED Gemini 額度或速率限制已觸發。 等待 App 倒數重試、換可用 Gemini key，或檢查 Google 專案額度與帳單。
HTTP 500 / INTERNAL Google 端發生非預期錯誤，或輸入上下文太長。 稍後重試、縮短會議背景或輸入內容、切換模型，並查看 Gemini API 狀態頁。
HTTP 503 / UNAVAILABLE Gemini 服務可能暫時過載或不可用。 稍後重試、切換模型，並查看 Gemini API 狀態頁。
HTTP 504 / DEADLINE_EXCEEDED Gemini 無法在期限內完成處理，常見於輸入內容過大。 縮短會議背景或音檔內容，保持 App 在前景後重試。

官方來源：Gemini API troubleshooting guide、Gemini audio understanding。

隱私摘要

Trace 使用你自備且只存於 iOS Keychain 的 Gemini API key；音檔與相關內容會送到 Google Gemini API。長音訊會透過 generateContent 分段處理，必要時使用 Google Files API 上傳；Trace 會在處理結束後盡力刪除上傳檔案。完整資料類型、保留期限與使用者選擇請參考 隱私政策。
