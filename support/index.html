Trace 支援。

如果轉錄或分析失敗，請先檢查 Gemini API key、專案額度、音訊格式與 app 前景處理狀態。本頁整理常見 Gemini API 錯誤、可嘗試的處理方式與隱私摘要。

處理失敗時

Trace 可直接錄下會議，或從「檔案」與「語音備忘錄」匯入音訊，再使用你自備的 Gemini API key 產生逐字稿、會議紀錄、決策、風險與待辦。

Apple Watch 錄音

Trace 可在 Apple Watch 本機錄音。完成後，錄音會傳到已配對的 iPhone，並在下次開啟 Trace 時出現在「錄音」區；手錶會保留副本直到 iPhone 確認已穩定收到。若尚未出現，請確認兩台裝置仍配對、已解鎖並可連線，然後開啟 iPhone 上的 Trace。

如果處理失敗，請先確認下方項目。若問題仍重複發生，可以透過 App Store 評論留下公開回饋。

如果你還沒有 Gemini API key，請先看 Gemini API Key 申請教學。如果想估算長音訊處理成本，請看 模型與成本。

聯絡支援前請先確認

請先確認：

  • 已允許 Trace 使用麥克風；若曾拒絕，請到 iOS「設定」重新開啟權限。
  • 已在「設定」輸入有效的 Gemini API key。
  • Gemini API key 所屬專案仍有可用額度。
  • App 保持在前景完成長音訊處理；若 iOS 中斷背景執行，可回到 app 重試未完成流程。
  • 匯入的檔案是 app 支援的音訊格式。
  • 若錄音被電話、其他 App 或音訊裝置中斷，回到 Trace 確認錄音狀態後再繼續或完成。
  • 若音檔或結果分享失敗，重新開啟該項目並再次使用系統分享表單。

Gemini API 錯誤說明

Trace 使用你自己的金鑰，從裝置直接向 Google Gemini API 送出請求。哪些內容已儲存、正在等待或尚未完成，請以 App 當下的工作狀態為準。

先找符合的情況。排查時保留原音檔與既有結果；單一錯誤訊息不能證明資料已遺失或已成功儲存。

  • 錄音未能完成
  • 逐字稿只到一半
  • 網路中斷或處理逾時
  • 額度或速率限制
  • 金鑰、權限或帳務
  • 模型或檔案資源找不到
  • Google 服務暫時異常
  • 請求內容或參數不被接受

錄音未能完成

發生什麼事：停止收尾失敗，不代表原音訊已遺失，也不代表已完整儲存。

目前狀態： 這段音訊可能仍在等待收尾。只有錄音出現在列表且能完整播放，才可確認可用；錯誤提示本身不能保證已保存。

下一步：先回錄音列表查看。1.3.1 起，若有「等待恢復」，可點選該錄音重試；1.3.0 或更早版本可關閉並重開 Trace 再查看。請勿刪除 App 或原音檔。

逐字稿只到一半

發生什麼事：Google 回傳文字仍可能缺少後半段；有文字或完成回應不等於內容完整。

目前狀態： 已回傳的文字可能只有部分內容；開頭、中間或尾端都有可能缺漏。時間戳檢查不能保證每一句都被辨識。

下一步：當 Trace 偵測到缺尾且符合恢復條件時，會嘗試恢復；只有工作狀態顯示重試時才代表已安排處理。若已顯示完成但內容明顯缺尾，保留音檔與結果並透過 App Store 評論回報；不要刪掉原結果或反覆提交整段錄音。

網路中斷或處理逾時

發生什麼事：這次連線或處理沒有在期限內完成，不能由錯誤本身判定 Google 是否已完成工作。

目前狀態： 工作可能處於失敗、等待重試或處理中；請以原工作的狀態為準，勿把逾時視為已取消 Google 端處理。

下一步：確認網路後回到 App，依工作狀態恢復未完成部分。若畫面顯示等待，先等候；不要同時建立重複工作，也不必先裁掉音訊。

額度或速率限制

發生什麼事：HTTP 429 可能是短期速率限制，也可能是每日或專案額度不足；換同一專案的金鑰不一定有用。

目前狀態： 這次請求受到限制，整份工作不一定已完成；已完成部分與下一次重試時間以 App 顯示為準。

下一步：只有畫面出現倒數時才代表已安排重試。若持續失敗，到 Google AI Studio 檢查專案限制與帳務；不要連續按重試。

金鑰、權限或帳務

發生什麼事：401 通常與驗證有關；403 也可能涉及專案權限或存取條件，不能一律判定金鑰貼錯。

目前狀態： 這次請求未獲正常授權或存取；此錯誤不代表裝置上的原音檔或既有結果已被刪除。

下一步：依錯誤提示檢查 Trace 設定中的金鑰，以及 Google AI Studio 的金鑰、專案存取與帳務狀態。請勿把金鑰貼到支援信件、截圖或網站。

模型或檔案資源找不到

發生什麼事：HTTP 404 可能指模型不可用，也可能是 Google 上的檔案或工作資源已不存在。

目前狀態： Google 端的指定資源無法使用，不等於本機音檔消失；先確認原工作是否仍有可用來源。

下一步：先查看 App 提示；模型問題可在設定更新模型清單，未完成工作則依原工作恢復。切換模式是另一個使用者選擇，可能影響結果與費用，不是通用的修復步驟。

Google 服務暫時異常

發生什麼事：HTTP 500 或 503 通常表示服務端處理失敗或暫時不可用；不能據此保證 Trace 或輸入內容完全沒有問題。

目前狀態： 這次處理未正常完成；是否保留已完成部分或排定重試，須查看 App 的原工作狀態。

下一步：查看 Google 服務狀態，稍後從原工作重試。若反覆發生，保留錯誤代碼與發生時間，透過 App Store 評論回報，不必先更換模型或刪除音檔。

請求內容或參數不被接受

發生什麼事：HTTP 400 表示 Google 無法接受這次請求；也可能有更明確的金鑰、帳務或功能限制訊息。

目前狀態： 這次請求被拒絕，不能視為轉錄完成；先保留原音檔與現有結果。

下一步：先依具體提示處理。若沒有明確原因，確認 App 為最新版本並透過 App Store 評論回報；不要為了嘗試而先刪除錄音內容。

找不到相符情況？請記下錯誤代碼與大約時間，查看工作狀態後透過 App Store 評論回報；不要附上金鑰或私人音訊。

隱私摘要

Trace 使用你自備的 Gemini API key，金鑰只存在這台裝置上；音檔與相關內容會送到 Google 處理。較長的音檔會分段處理，音檔在處理期間暫時存放在 Google 的伺服器，Trace 會在處理結束後盡力刪除。完整的資料類型、保留期限與你可以做的選擇，請參考 隱私政策。
